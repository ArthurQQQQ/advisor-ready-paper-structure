# 用段落排名稳定度决定长文档证据检索何时停读

## 引言

**问题。** 在 QASPER 的同一批可由正文段落回答的问题上，与读到固定 token 上限相比，按段落排名稳定度停读能否在相近的平均阅读预算下提高金标证据段落召回率？

**假设。** 逐段判断排序是否稳定，可以为需要更多正文的问题分配更高预算。[待填：为什么排名稳定度应该反映证据已充分，以及哪种情况会误停。]

## 方法

按文档原序逐段开放正文，使用同一段落评分器更新前五名。每个问题的评分器和候选顺序对各策略一致。

- [待填：正文筛选、拆段、tokenizer、段落 ID 与金标映射。]
- [待填：稳定度定义、最小读取量、连续稳定步数、阈值与并列排名规则。]
- [待填：所用评分器、冻结条件和新增正文以外的开销。]

## 实验

以 QASPER 原始标注为证据来源。预先定义可由正文段落回答的样本、图表证据的处理和多份标注的汇总规则。主指标为段落 Recall@5，另报金标证据出现在后半段的子集结果。[QASPER 原论文](https://aclanthology.org/2021.naacl-main.365/)

| 对照或来源 | 对本问题的作用 | 比较条件 |
| --- | --- | --- |
| 固定 token 前缀 | 主对照，检验随问题调整阅读量的收益 | 用开发集选择全局上限以匹配平均预算，测试集报告实际预算差。 |
| 同一评分器读完整篇 | 完整输入下的质量参考 | 同一数据、评分器、候选顺序与 top-5。单列实际阅读成本。 |
| QASPER 的 TF-IDF | 原论文的简单证据检索参照 | 原论文报告 Evidence F1。需在同一子集、前缀、预算及 Recall@5 下重跑。[原论文表 3](https://aclanthology.org/2021.naacl-main.365.pdf) |
| Answer-Convergence Stopping（ACS） | 最接近的动态停读方法 | 衡量生成答案的置信度与稳定度。要纳入比较，需在相同输入和预算下输出可评分的段落 ID，并另报生成开销。[作者预印本](https://arxiv.org/abs/2609.34590) |
| FLARE | 置信度触发额外检索的相关工作线索 | 生成时从外部语料发起检索，输入与停止决策不同。单列为相关工作。[原论文](https://aclanthology.org/2023.emnlp-main.495/) |

**事前约定。** 对所有采用的停止策略固定数据划分和评分器。停止规则在开发集设定，冻结后评估测试集。预先填入可接受的预算差和按题配对的不确定性报告方式。若达到预算匹配后稳定度停读仍未提高 Recall@5，当前假设得不到支持。
