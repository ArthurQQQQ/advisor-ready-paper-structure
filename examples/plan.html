Review summary 审阅摘要

Frame the Abstract and Introduction around passage retrieval. Start Results with the paired pilot and reserve a later subsection for comparisons across PDF layouts.

In a paired pilot on 24 questions from single-column PDFs, the reranker with layout cues retrieved the annotated top passage on 15 questions versus 12 for the text-only reranker (E02).

The result describes this pilot. Claims about other layouts, answer accuracy, and the individual contribution of section headings require different evidence.

Priority checks 优先核对

  1. G01 Rebuild the paired comparison. Join both system runs to the same question IDs, gold annotations, and candidate pools. Record eligible pairs and exclusions by layout before computing scores.
  2. G02 Measure the paired effect. Tabulate both-correct, layout-only, text-only, and neither outcomes. Report denominators and uncertainty alongside the paired difference.
  3. G03 Separate the feature effects. On the fixed pairs and pools, compare the joint configuration with page-position-only and headings-only runs if the paper retains a feature-level claim.

G04 Fix the endpoint in the draft now. Check the claim against E01. This study measures passage retrieval. Keep answer accuracy open.

Recommended paper structure 建议结构

The English text explains what each part does. The notes alongside it name the next edit. Use each gap ID to find the same action in the revision table.

Abstract

Draft last. State the retrieval question, the combined layout inputs, and the result for the eligible evaluation population.

G04 可先修订把回答准确率改为首位段落与标注段落的匹配。

G01–G02 待补结果段确认后再写摘要。核对适用范围、分母和指标。

1. Introduction

Open with the task of selecting an annotated evidence passage from a fixed candidate set. Introduce layout as information for reranking and end with a retrieval question.

G01 待补等配对评估确定覆盖范围后，再写最后一段的主要发现。

2. Method and evaluation

Follow the input through the shared candidate pool, layout-aware reranker, and top-ranked passage. Define the match criterion before explaining the comparison.

G01 待补写清问题、候选池和标注的配对条件，以及排除标准。

3. Results

Open with the question that the paired comparison addresses. Describe how to read the table by PDF layout, report the observed differences, and tie them to the joint layout configuration. Present the pilot at its actual scope.

G02 待补补齐每道题的成对结果和不确定性。按分母解释差异，表格与图例等待核算。
