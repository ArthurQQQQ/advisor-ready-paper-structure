# Reference-Guided Paper Figures

Turn a visual direction the author likes into a consistent figure family while preserving the paper's evidence and uncertainty. This skill also works as the figure-production module of advisor-ready-paper-structure.

## Establish content and style separately

Read the current figure, relevant manuscript passage, source data, and supplied reference images. Record a figure brief with its reader question, exact content, evidence/gap IDs, proposed versus completed status, intended width, and output format. Keep the author's ambitious claim, proven result, and empirical evidence distinct; identify missing support without changing the research direction.

Reuse an already approved reference. Do not reopen style selection merely because this skill was invoked. For a newly requested reference search, inspect actual figure pixels and verify paper/figure/version and publication status from primary sources. Acceptance and appearance do not establish image-generation provenance. Borrow organization and visual treatment; retain the current study's own content.

For the soft, illustrated scientific style approved in this workflow, read [the style profile](references/soft-scientific-style.md). Use its palette and object vocabulary as a starting profile, not a compulsory style for every author. The [generic style board](assets/soft-scientific-style.svg) contains no research measurements or unpublished study material.

If a local installation includes `assets/author-approved-reference.png`, inspect it as the retained style-only reference unless the author selects a newer one. Its study content does not become evidence for another paper. This optional local image is separate from the distributable generic board.

## Choose the rendering route

| Content | Production route |
| --- | --- |
| Concept, construction flow, example, or semantic timeline | Available image-generation tool for illustrations; vector/typesetting tools when exact labels, connectors, or editability warrant them. |
| Measured bars, curves, intervals, heatmaps, or count tables | Deterministic plotting/typesetting from the actual frozen data. Image generation must not draw numerical geometry. |
| Mixed concept and measured result | Build the illustration and data panel separately, then compose while preserving both sources. |

For image edits, inspect the target first and provide it through the tool's supported image-reference mechanism. Distinguish an edit target from a style-only reference. Preserve the original and use a separate output version. If rendering is unavailable, deliver the brief and prompt and state that the image has not been rendered.

## Produce and verify

Use [the production brief and checks](references/production-and-checks.md) for prompts, figure families, and paper replacement. Review generated pixels against the source brief: exact labels, quantities, scope, arrow endpoints, branch conditions, chronology, and qualifiers. Correct misleading content before integrating the image. Generated text must be read, not assumed correct.

For a data plot, verify denominators, unknown/missing categories, source counts, scales and intervals. Separate intended targets from achieved observations. Reuse the illustration's palette and type hierarchy without changing the measurements. Check at the final manuscript width and in grayscale.

Store the brief, prompt, reference provenance, original generated file, and final exports with the paper. Identify raster PNGs and raster-containing PDF wrappers accurately; only describe an output as editable vector after creating and inspecting it. When replacing figures, keep previous versions, compile and render the complete PDF, inspect the changed pages, and verify that scientific text, tables, and data have changed only where requested.

Figure production does not authorize new experiments, paid annotation, manuscript upload, email, submission, or GitHub publication of private research. Carry out those actions only within the user's current authorization. A public skill package should contain generic assets and instructions; keep study-specific source images and evidence in the study workspace unless publication is separately authorized.
