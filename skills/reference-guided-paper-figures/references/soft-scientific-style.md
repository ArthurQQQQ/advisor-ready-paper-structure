# Soft scientific illustration profile

This profile captures an author-approved paper figure family: a construction overview, a semantic timeline, and an exact composition plot. It is a reusable visual preference, not evidence for any benchmark or a required publication style.

## Visual grammar

- White canvas; dark navy text (`#101B46`), using a clear sans serif such as Arial or an available equivalent.
- Pale lavender (`#E7E5FF`) stage headers; teal (`#BEEFEB`) source objects; orange (`#FFBA83`) provenance links and local emphasis; blue (`#4975F5`) process arrows. Use gray (`#D9DDE8`) plus a hatch or explicit label for uncertainty where relevant.
- Use folded paper stacks for source collections, a small calendar or clock for time, a highlighted quote for source evidence, a linked compact record for an extracted unit, and a checklist for verification.
- Show operations with clear directed connectors. Reserve a second arrow treatment for provenance or evidence links and include a legend when the distinction is not obvious. A container means shared scope or stage, not causal support.
- Soft rounded corners, thin colored outlines and restrained shadows may help the object hierarchy. Keep data geometry flat and exact. Avoid decorative gradients that obscure plot boundaries or a second competing illustration style.
- Use a few short stage headings and concrete object examples. Let the caption carry the full explanation. Preserve necessary qualifiers even if that requires another panel rather than smaller text.

The [generic board](../assets/soft-scientific-style.svg) illustrates the palette, source object, evidence link and verification record. Its labels describe the workflow; they are not a dataset, a result, or a replacement for the author's actual figure reference.

## Layout decisions

Start with the reader's question, then choose the minimum panel sequence that explains it. A common construction overview is **source objects → transformation with one concrete example → verified output and uncertainty**. Use a different sequence when the science requires it. Do not force every diagram into three panels.

Give inputs and outputs recognizable object shapes; use an expanded example to explain the consequential transformation. Align related events on one time axis and put reference-time selection visibly apart from observations. Do not depict observation time as a physical change point unless evidence identifies it.

Across the figure family, retain palette roles, type hierarchy, icon vocabulary and connector meaning. A timeline can use more whitespace than a construction overview; a data plot can use the same colors with no shaded cards. Match explanatory purpose before matching decoration.

## Prompt fragment for an illustration

```text
Create a publication-sized scientific illustration with the attached author-approved image as a STYLE reference. Preserve the separately supplied scientific brief exactly. White background, dark navy sans-serif text, pale lavender stage headings, pale teal source cards, restrained orange evidence highlights, clear blue process arrows. Concrete paper/calendar/linked-record objects, thin outlines, subtle shadows, generous whitespace, short readable labels. Use the specified panel order and exact labels. Keep unknown or proposed content visibly labeled. Put numerical results only where the brief supplies verified values; measured plot panels will be composed separately with plotting tools.
```

Attach the current target when editing it. Identify each supplied image as target or style reference in the actual tool prompt. Do not include unrelated study facts from a reference image. Do not promise that a palette will guarantee venue acceptance.

## Reference provenance

Prefer the actual image the author selected over a newly inferred aesthetic. If recent venue examples are requested, record source title, URL, figure number/page, version/date, observed design traits, and what is being borrowed. Check visual details from the image itself. Link external figures rather than copying their artwork into a distributed skill without a suitable right or license.
